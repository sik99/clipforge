# ClipForge

A video-conversion server with a minimalist web client, built to learn distributed system architecture and operations on the path toward a Software Architect role.

The intended server platform is ASP.NET Core. The system will evolve through product requirements and measured operational limits, with emphasis on horizontal scaling, deployment, infrastructure, observability, and debugging.

**Current stage:** documentation and design preparation; no application is implemented yet.

Start with the [project brief](docs/project-brief.md) for scope, preferences, and open decisions. See the [repository layout](docs/repository-layout.md) for document placement and [AGENTS.md](AGENTS.md) for agent guidance.
